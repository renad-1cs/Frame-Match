API Testing

This folder contains the API testing information for the Frame Match project.

Backend URL

http://localhost:8082

Tested API Endpoints

Method	Endpoint	Description
GET	/api/frames	Get all glasses frames
GET	/api/faceshapes	Get all face shapes
GET	/api/matches	Get face shape and frame matches
GET	/api/face-analysis/recommend/{id}	Get recommended frames for a face shape

Testing Tool

The GET endpoints were tested using a web browser.

Note

The backend must be running before testing the endpoints.
